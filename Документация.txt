1. ЧТО ЭТО ЗА ПРОЕКТ
---------------------------------------------------------------------

Это сайт компании. Он написан на Nuxt 4 — это готовый каркас для сайтов
на Vue (JavaScript). Проще говоря:

  - сайт собирается из «кирпичиков» (компонентов) — шапка, баннер,
    блок с цифрами, форма заявки и т.д.;
  - каждый кирпичик — отдельный файл .vue;
  - страница — это просто список кирпичиков, идущих друг за другом.

Стили пишутся на SCSS (это CSS с переменными и вложенностью, при сборке
он сам превращается в обычный CSS).

У сайта есть маленькая серверная часть: форма «Обратная связь»
отправляет заявку в CRM Битрикс24 (создаётся лид).

2. КАК ЗАПУСТИТЬ У СЕБЯ
---------------------------------------------------------------------

1) Установить Node.js версии 22 (установщик лежит в корне:
   node-v22.18.0-x64.msi).
2) Открыть папку проекта в терминале (например, в VS Code).
3) Один раз установить зависимости:
       npm install
4) Запустить сайт:
       npm run dev
5) Открыть в браузере: http://localhost:3000/

Пока запущен npm run dev, любые изменения в файлах сразу видны
в браузере (страница обновляется сама).

Если Windows ругается «выполнение сценариев отключено», выполнить
в PowerShell от администратора:
       Set-ExecutionPolicy -ExecutionPolicy Unrestricted -Scope Process

ВАЖНО: чтобы форма заявки работала, в корне должен лежать файл .env
со строкой:
       BITRIX_KEY=<ключ вебхука Битрикс24>
Этого файла НЕТ в репозитории (он секретный, это нормально).
Ключ нужно взять у владельца портала nanosoft.bitrix24.ru.
Без него сайт работает, но заявки никуда не уходят.


---------------------------------------------------------------------
3. КОМАНДЫ
---------------------------------------------------------------------

  npm run dev       — запуск для разработки
  npm run build     — сборка для боевого сервера (результат в .output/)
  npm run preview   — посмотреть собранную версию локально

Сборка запускается на сервере так:
       node .output/server/index.mjs
Серверу нужен Node.js 22 и тот же .env с BITRIX_KEY.

Не используйте «npm run generate» (чисто статичный сайт) — в этом
режиме не будет работать отправка формы в Битрикс24.

5. СТРАНИЦЫ — app/pages/
---------------------------------------------------------------------

Адрес страницы = имя файла.

  index.vue                 → /                       (главная)
  Integration-bitrix24.vue  → /Integration-bitrix24   (внедрение Битрикс24)
  server-rent.vue           → /server-rent            (аренда серверов)
  technicalWork.vue         → /technicalWork          (заглушка «тех. работы»)
  services/index.vue        → /services               (черновик, см. п.11)
  services/[service].vue    → /services/<название>    (черновик, см. п.11)

Внутри страницы почти нет кода — только перечень блоков, например:

    <BlocksServerRentHero />
    <BlocksServerRentTariffs />

Чтобы поменять порядок блоков на странице — просто переставьте строки.

7. КОМПОНЕНТЫ (БЛОКИ) — app/components/
---------------------------------------------------------------------

  header.vue          — шапка сайта (меню, телефон, почта)
  footer.vue          — подвал (контакты, карта)
  ui/frame.vue        — декоративная рамка-«скоба» (используется в блоках)
  modal/              — всплывающее окно (только на черновых страницах услуг)

  blocks/             — блоки страниц:
     starting, company, whyChoose, numbers, ourServices, directions,
     ctaBanner, companys, certificates          → блоки главной
     callback                                   → форма заявки (на всех страницах)
     bitrix24/...                               → блоки страницы Битрикс24
     serverRent/...                             → блоки страницы аренды серверов

КАК ИМЯ ФАЙЛА СВЯЗАНО С ТЕГОМ (важно понять один раз):
Nuxt сам подключает компоненты по пути к файлу, импортировать их не нужно.
  components/blocks/numbers.vue          → <BlocksNumbers />
  components/blocks/bitrix24/hero.vue    → <BlocksBitrix24Hero />
  components/ui/frame.vue                → <UiFrame />

Файл .vue состоит из двух частей:
  <template> — HTML-разметка блока (тексты меняются здесь)
  <script>   — логика блока (если есть)
Стилей внутри .vue-файлов нет — они вынесены отдельно (см. ниже).

8. СТИЛИ — app/assets/styles/
---------------------------------------------------------------------

  main.scss        — ГЛАВНЫЙ файл. Подключает все остальные стили и содержит
                     общие классы для всего сайта: .wrapper (ширина секции),
                     .btn (кнопка), .label (метка «••• ЗАГОЛОВОК»),
                     .title, .text, .cutCorners (рамка со срезанными углами)
                     и т.д. Также здесь подключается шрифт (Noto Sans SC).

  variable.scss    — ПЕРЕМЕННЫЕ: цвета, размеры шрифтов, ширина контента,
                     высота шапки, точки адаптива (телефон/планшет/ноутбук).
                     Хотите поменять цвет на всём сайте — меняете здесь.

  components/      — стили каждого блока. Файл называется так же, как блок:
                     components/blocks/numbers.vue
                        ↔ styles/components/numbers.scss
                     components/blocks/bitrix24/hero.vue
                        ↔ styles/components/bitrix24/hero.scss

Правила, по которым написаны стили (соблюдайте их дальше):
  - Цвета берутся только функциями из variable.scss:
        color-orange()      — оранжевый
        color-white(.5)     — белый с прозрачностью 50%
    а не вписываются вручную (#FFB11A и т.п.).
  - Адаптив — через готовые обёртки:
        @include tablet { ... }   (экран до 768px)
        @include phone  { ... }   (до 500px)
        @include laptop { ... }   (до 1024px)
  - Имена классов по схеме БЭМ: блок__элемент--модификатор
        .numbers__item, .numbers__item--active

НОВЫЙ SCSS-ФАЙЛ НЕ ЗАРАБОТАЕТ, пока его не подключить в main.scss строкой
        @use './components/имяФайла';
Если имя совпадает с уже подключённым файлом из другой папки, добавьте
псевдоним: @use './components/bitrix24/advantages' as bitrixAdvantages;

9. СКРИПТЫ И ДАННЫЕ — app/assets/

  composables/useScrollToAnchor.js — плавная прокрутка к нужному блоку
                        при клике по меню (с учётом высоты шапки).

  Анимация «прорисовки» SVG-иллюстраций при прокрутке — функция
  svgAnimator внутри pages/index.vue.


---------------------------------------------------------------------
10. ФОРМА ЗАЯВКИ → БИТРИКС24
---------------------------------------------------------------------

  1) Посетитель заполняет форму в блоке components/blocks/callback.vue.
  2) Форма отправляет данные на адрес сайта /api/sendCallback.
  3) Файл server/api/sendCallback.post.js создаёт лид в Битрикс24
     (портал nanosoft.bitrix24.ru) с помощью ключа BITRIX_KEY из .env.

Если заявки перестали приходить — первым делом проверьте ключ в .env
на сервере и что вебхук в Битрикс24 не удалён.

12. ТИПОВЫЕ ЗАДАЧИ — КУДА ИДТИ
---------------------------------------------------------------------

  Поменять текст на странице
      → найти блок в app/components/blocks/..., править <template>.
        Быстрый способ: поиск по всему проекту (Ctrl+Shift+F в VS Code)
        по куску текста с сайта.

  Поменять цвет / шрифт / отступ
      → стиль блока в app/assets/styles/components/...
        Цвет для всего сайта → app/assets/styles/variable.scss

  Поменять телефон / почту
      → app/components/header.vue и app/components/footer.vue

  Добавить новый блок
      1) создать app/components/blocks/myBlock.vue
      2) создать app/assets/styles/components/myBlock.scss
         (первой строкой: @use '../variable' as *;)
      3) подключить стиль в main.scss
      4) вставить <BlocksMyBlock /> в нужную страницу

  Добавить новую страницу
      1) создать app/pages/my-page.vue (адрес будет /my-page)
      2) добавить SEO-запись в pagesSEO в app/layouts/default.vue
      3) при необходимости — ссылку в меню (header.vue) и в sitemap.xml

  Заменить картинку
      → положить файл в public/images/... с тем же именем.
